# Güvenlik bildirimleri

Oturum, paylaşım yetkisi, kişisel veri veya anahtar açığını proje sahibine özel kanaldan bildirin. Yeni GitHub deposunda özel güvenlik bildirimleri etkinse o kanalı kullanın. Gerçek anahtar/çerez/kullanıcı kaydını açık issue içine koymayın.

Kaynak sürümünü, tekrar üretme adımlarını ve kişisel veri içermeyen örneği belirtin. Yetkiniz olmayan sepetler üzerinde deneme yapmayın.

Sunucu sırları `.env.example` içine yazılmaz. `.dev.vars`, `work/`, yerel veritabanları ve DPAPI dosyaları sürüm kontrolü dışındadır. Sites kimliği yalnız güvenilir platform akışından kabul edilir; yerel test girişi üretim üyeliği değildir.
